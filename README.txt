STUDY HUB — PERSONAL SSC STUDY WORKSPACE

Open index.html in a modern browser. This is a local-first starter build. Cards, notes, tasks, review history, goals and preferences are stored in that browser's localStorage. Export a JSON backup regularly from Settings.

Included features:
- Responsive premium interface with Midnight, OLED black, Light and Lavender themes.
- Handwritten image/PDF OCR using browser Tesseract.js and PDF.js. OCR quality varies substantially; handwritten and mixed Hindi/Hinglish/math may be inaccurate. Always correct the editable OCR result before using it.
- Free ChatGPT-assisted flashcard workflow: copy corrected notes with a prompt, paste into ChatGPT, then import its JSON response. No API key is required for this manual workflow. This is not an embedded AI API integration.
- Manual flashcard creation, search, edit, duplicate and delete.
- Export flashcards separately as a clean JSON array containing only each card’s front and back; no review history, subjects, notes, tasks or other app data.
- Spaced repetition with an SM-2-inspired ease/interval scheduler (not FSRS). Again/Hard/Good/Easy ratings update saved intervals.
- Notes, task planning, monthly calendar, timeline and expanded analytics: study hours, 7-day focus chart, flashcard mastery, review ratings, task completion, notes, subject breakdown, game rounds and recent activity. Analytics are based on data saved locally in this browser.
- Task-linked Pomodoro timer with configurable focus and break lengths. Completed sessions are recorded against tasks.
- Daily, weekly and monthly study-hour goals with remaining-hours countdown and progress bars. Goal totals are based on completed Pomodoro focus sessions.
- Focus-session target counter and ambient sound generator (soft rain-style noise, brown noise, pink noise and a soft tone). Audio starts only after the user taps Play.
- Optional task-time browser reminders. Enable browser notification permission; reminders are checked while this page is open. They are not guaranteed if the browser is closed or suspended.
- JSON backup and restore; local browser storage only.

Important limitations:
- No cloud sync, account login or server push notifications.
- iOS may suspend timers/audio/notifications when Safari is backgrounded or the phone is locked. Reopen the app to refresh saved timer state.
- Browser OCR depends on internet access to load the OCR/PDF libraries and language data. OCR is not handwriting-specialist AI.
- ChatGPT-assisted card generation requires copying the prompt to ChatGPT and pasting the JSON response back; it is not an automatic in-app API call.
- Spaced repetition is SM-2-inspired, not genuine FSRS.
- Reminder notifications work only while the page is active and permission is granted.
- Calculation games: timed 60-second rounds with addition, subtraction, multiplication, division and percentage questions; easy/medium/hard levels; score, streak, accuracy and locally saved best score. Questions are generated offline on the device.
